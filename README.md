# Database Lab 1 – PostgreSQL

## Objective
The objective of this lab is to understand the basics of relational databases using PostgreSQL.  
This lab focuses on creating tables, inserting data, executing queries, taking database backups, and managing the project using GitHub.

## Description
This lab demonstrates fundamental PostgreSQL operations including:
- Creating a relational database table using SQL
- Applying constraints such as PRIMARY KEY, NOT NULL, CHECK
- Inserting multiple records into a table
- Executing SQL queries for data retrieval and verification
- Creating a database backup using PostgreSQL tools
- Using Git and GitHub for version control and submission

## Database Details
- **Database Name:** `lab1_db`
- **Table Name:** `books_read`
- **Primary Key:** `book_id`
- The table stores information about books including title, author, category, number of pages, date finished, rating, and notes.

## Files Included
- **books_read_table.sql**  
  Contains the SQL commands to create the `books_read` table with appropriate constraints.

- **queries.sql**  
  Contains SQL queries written for lab exercises such as selecting, filtering, and verifying data.

- **lab1_db_backup.dump**  
  A complete PostgreSQL database backup to ensure data safety and reproducibility.

## Tools & Technologies Used
- PostgreSQL (Database Management System)
- SQL (Structured Query Language)
- Git & GitHub (Version Control)
- Kali Linux (Operating System)

## Learning Outcomes
After completing this lab, the student is able to:
- Design and create database tables
- Use SQL constraints effectively
- Insert and retrieve data from a database
- Take and restore database backups
- Manage database projects using GitHub
